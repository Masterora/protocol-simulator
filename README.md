# protocol-simulator

用于联调 IEC104、Modbus TCP / RTU 的桌面规约模拟工具。可作为主站发送命令，也可作为子站模拟遥信、遥测、遥控和遥调，支持自动变化、定时上报与报文查看。

## 下载与运行

使用交付的 `protocol-simulator.zip`，或查看仓库的[正式发布版本](https://github.com/Masterora/protocol-simulator/releases)。解压后运行对应系统的程序：

| 系统    | 程序                     | 运行要求                                                |
| ------- | ------------------------ | ------------------------------------------------------- |
| macOS   | `protocol-simulator.app` | macOS 12.3 或更新版本；包含 Apple Silicon 和 Intel 架构 |
| Windows | `protocol-simulator.exe` | Windows 10/11 x64，已安装 WebView2                      |

macOS 应用目前使用本地签名。如果系统阻止打开，可在“系统设置 → 隐私与安全性”中允许打开。

## 第一次模拟 IEC104 上报

1. 启动应用，在顶部切换到“子站”。新工程中的通道默认停止。
2. 打开“通道设置”，选择 TCP 服务端，填写本机监听 IP 和端口。
3. 点击装置列表右侧的 **＋**，选择 IEC104，填写公共单元和四遥的首点位、数量。遥测默认使用短浮点。
4. 在平台或主站配置相同的 IP、端口、公共单元、点位及数据类型，并下发配置。
5. 回到工具点击“连接”，等待主站接入并激活 IEC104 链路。
6. 在遥信或遥测页打开“自动上报配置”，设置点位、变化方式和周期，保存。
7. 配置发生有效更改后，重新手动连接，再点击“开启自动上报”。在平台核对属性值是否随对应点位变化。

平台需要能够访问工具监听的 IP。使用 VPN 时，应填写实际可回连的网卡地址；仅有 TCP 连接还不代表 IEC104 链路已经激活。

无需外部平台时，可打开[本机四遥联调示例](examples/automatic-loopback.json)。先在子站连接示例服务端，再切换主站连接示例客户端；工程不会自动连接或启动任务。

## 遥控与遥调

- **子站遥控**：在遥控页配置下发点位与遥信点位的绑定，可选择反向。主站执行后，绑定遥信改变并反馈。
- **子站遥调**：在遥调页绑定遥测。设值命令写入下发值，步调节命令基于绑定遥测当前值增减。
- **主站操作**：支持选择、执行、撤销、直控，以及对应的自动遥控、自动遥调配置。执行结果在四遥页的“运行详情”查看。

选择、撤销、否认和不应答不会改变绑定值。配置窗口只保存参数，运行开关始终位于主界面。

## 编辑、保存与日志

- 单击点表单元格编辑，Enter 提交，Esc 取消。搜索可匹配点位或描述，每页最多 100 条。
- 装置点表使用“首点位＋数量”；批量操作使用 `1，3-5，8` 这样的混合点位输入。
- 有效的配置更改会断开对应通道，之后需要手动连接。在线修改点值、品质和批量设值保持连接；IEC104 子站继续上报。
- “保存”将点表、配置和规则写入 JSON 工程。重新打开工程保持停止状态，各工程窗口互相独立。
- 日志筛选栏始终可见，可搜索连接地址、选择方向或查看全部通道。暂停报文显示不会停止通信。

## 常见问题

**已连接但平台没有数据？** 检查平台配置是否已下发、IEC104 是否激活、公共单元和点位类型是否匹配，再核对是否已开启上报。

**提示“归一化遥测范围为 -1 ≤ 值 < 1”？** 归一化格式不能表示 100、220.5 等数值。需要这些数值时，选择短浮点或适用的标度化格式。

**遥控、遥调没有改变属性？** 检查主站下发点位、子站绑定目标和数据类型，并查看执行确认、执行结束及反馈报文。请求发出不等于执行成功。

**更新应用会自动恢复连接吗？** 不会。先保存工程，更新后打开工程，再手动连接和启动任务。“更新”按钮只检查正式版本并打开下载页，不自动覆盖应用。

## 支持范围与开发资料

支持标准 IEC104、Modbus TCP/RTU，以及 RAW TCP、UDP、串口通信。厂商私有 SOE、虚遥信、五防闭锁等扩展不在完整兼容范围内。

构建方法、测试命令及平台验收边界见[构建与验证](https://github.com/Masterora/protocol-simulator/blob/main/CONTRIBUTING.md)。
