protocol-simulator — Go + Wails 深色版（IEC104 自动批量遥控／遥调）

启动
双击 protocol-simulator.exe。Windows 10/11 x64，需要 Edge WebView2 Runtime。
启动、打开工程和新建工程都不会自动连接设备。新建工程打开独立主窗口，按当前主站／子站模式准备一个停止状态的“通道1”；原工程与通信不受影响。各窗口的通道、装置、自动任务、保存路径互相独立。
保存和另存为的默认文件名使用当前工程名称，例如“工程1.json”；已保存工程再次点击保存仍写入原路径。保存／另存为成功后，工程名称同步为最终文件名（不含.json）；取消或保存失败不改名。
启动默认工程名称为“工程1”，连续新建默认使用“工程2”“工程3”…，可自行修改名称，取消不占用编号。
启动后直接进入居中的主站工作区，默认准备“通道1”；通过顶部菜单切换主站／子站，不再显示初始选择窗口。切换模式保留窗口位置和尺寸。
通信：选择通道 →“通信”，Client 修改远方 IP／端口，Server 修改监听 IP／端口。
需要指定客户端本地绑定时勾选对应选项，输入本地 IP／端口。地址支持主机名和 IPv6。
点击左侧通道／装置标题右侧“+”新增；创建窗口可填写名称，默认使用未占用的“通道N”／“装置N”。通道右键菜单依次为重命名、复制、删除。
首次增加装置默认选择104规约（标准版）；已选择的规约及已有装置配置保留。每行左侧为点位首地址，右侧为数量。
通信 IP／端口在连接时也可编辑；点击“应用”后，变更的通信参数生效、停止通道并关闭配置窗口，再手动点击“连接”。已停止的通道只保存，不自动启动。
无效参数不会断开原连接；通信参数实际变更时，自动任务结束，需要重新开始。通信管理中直接修改通道名称、通信方式、地址和本地绑定；串口模式可直接修改串口参数，无需“编辑”按钮。回车或离开输入框保存，Esc取消，刷新保留输入草稿。
所有输入框和下拉框取消上下微调及下拉箭头，保留直接输入、点击选择和输入范围校验；数值框禁用上下键增减值。
监听地址必须属于本机；报错“can't assign requested address”表示本机没有该 IP，可选择本机 IP 或 Any（监听所有网卡）。
监听 IP 可填写 Any，也可从本机 IP 候选中选择或手工输入；串口候选可刷新。
UDP 使用远方 IP／端口与独立的本地端口，不使用 TCP 的指定本地绑定选项。
关闭增加装置／通信窗口只隐藏；再次打开复用原窗口。重新打开通信会加载当前选中通道。
增加装置窗口 Enter／Esc 均隐藏，不增加装置；点击“确认”才增加。通信窗口 Enter 保存、Esc 不保存。

自动数据
选择 IEC104 或 Modbus 子站装置 →“自动数据”。每行一组，可同时配置多种数据、多个地址范围。
每组分别设置起止地址、周期（200–3600000ms）、变化方式和数值上下限／固定值／步长。
范围只作用于已经配置的点位；同一类型的启用范围不能重叠。遥测支持浮点数，Modbus 寄存器为0–65535整数，开关量为0／1。
变化方式：固定值、递增循环、区间随机；遥信／线圈／离散量另支持翻转。递增超过上限后回到下限。
“保存配置”只保存规则，不启动任务；规则随整个工程保存。重新打开工程不会自动启动或连接。
启动子站通道后点击“开始”；IEC104还需要主站连接并激活传输。暂停／继续保留进度，停止后可编辑规则并重新开始。
IEC104每组按独立周期更新点值并自发上送；Modbus只更新点值，由主站轮询读取，不发送不存在的主动上报帧。
关闭窗口只隐藏，任务在后台继续；停止通道、删除装置、更换点表、更换工程或退出程序都会结束相应任务。
IEC104默认勾选“通信中断自动停止”；取消时，断线期间等待，不积压周期，恢复连接后继续。

自动遥控
选择 IEC104 主站装置，点信息体上方“自动遥控”。
窗口按原版 AutoYKForm 的表格、异常输出、底部选项和计数栏排列。
表格列：序号、启用、点地址、点名称、遥控类型、遥控选择、遥控执行、遥控次数、遥信关联、变位结果。
每行默认启用、合闸后分闸、1 次；可以点击启用列、更改类型和次数。
右键表格 → 批量修改：勾选要修改的项目，可统一启用、类型、次数；确认生效，Esc 关闭不修改。
四种类型：合闸后分闸、分闸后合闸、合闸、分闸。
逐点按次数执行；合闸后分闸／分闸后合闸每次包含两次遥控，分别计数。
默认间隔 2ms、超时 10000ms；支持遥信判断、双点遥控、循环遥控、直控、失败自动暂停。
“自动遥控 → 暂停遥控 → 继续遥控”使用同一个按钮。
暂停在当前一次遥控结束后生效，继续从下一操作续跑，不重置计数。
“结束遥控”中止任务及等待，不会再发送后续选择／执行。
选择成功后才执行；选择／执行否认或超时记为失败，勾选“失败自动暂停”时在下一操作前暂停。
统计按每次合／分操作累计；异常输出保留实际错误原因。

遥信判断
在主站遥控点“编辑”窗口填写“遥信关联”：例如 1 表示地址 1，!2 表示地址 2 反向。
自动窗口显示对应遥信名称；勾选“遥信判断”后，执行成功还需收到满足目标状态的真实遥信值。
未关联的行不做遥信判断。不会用遥控确认伪造遥信变位。
工程 JSON 保存关联；CSV 有关联时追加可选 feedback 列，兼容原有五列表头。

自动遥调
在主站信息体上方填写点地址、类型和遥调数值，然后点“自动遥调”。
地址支持单地址、英文逗号及范围，例如 24833,24834 或 24833-24834。
原版会先列出单地址项，再追加范围展开项，重复项保留；本版保留该顺序，以弹出表格为准。
窗口五列：序号、点地址、点名称、遥调数值、是否已执行。
每行数值可单独编辑，Enter 或离开单元格提交；支持 10H 等十六进制整数写法。
类型继承主界面的归一化／标度化／浮点数选择；运行中改变类型会用于后续行。
归一化沿用 GYTest 的有符号 16 位原码，归一化和标度值范围为 -32768～32767 整数。
默认遥调间隔 200ms，逐行直接设值；没有另加原版不存在的暂停、循环或勾选列。
“自动遥调”开始后变为不可点，使用“结束遥调”停止；有效应答完成后才把该行标为“是”。

窗口和任务
自动遥控、自动遥调、批量修改均为独立 Windows 窗口，保留深色。
自动遥控／遥调窗口客户区分别按原版 925×402、516×386 配置，列宽比例来自原版 Designer。
点右上角关闭只隐藏窗口，保留位置、参数和任务；重新点击入口恢复原窗口及进度。
必须点“结束遥控／结束遥调”才停止该任务。
停止通道、删除原装置、更换工程或退出主程序都会结束相应任务。
自动任务绑定打开时的通道和装置，切换主窗口选择不会更换操作目标。
同通道自动任务与手动控制互斥，防止选择与执行的应答串到其他操作。
已经发出的命令无法撤回；在途结束或超时显示未确定结果时，重新连接通道后再发起控制。

本机示例
打开同目录“自动批量联调.json”。
1. 选择子站模式，选“本机子站”，点“连接”，监听 127.0.0.1:24040。
2. 切换主站模式，选“本机主站”，点“连接”。
3. 打开自动遥控，默认两点合分各一次，可看到总数 4、成功 4。
4. 自动遥调地址填 24833-24834，类型选浮点数，数值填 12.5，打开窗口后开始。
5. 切到子站查看对应遥控／设值点值；示例不会自动改变位置遥信，遥信判断需要实际反馈或对子站遥信改值后上送。
若 24040 已被占用，先停止通道，将双方通信配置改为相同的空闲端口。

其它功能
保留独立通信配置、手动遥控／遥调、总召／上送、点表导入导出、Modbus 多装置和 IEC104 再添加确认替换规则。
本轮自动操作实现 IEC104 45/46 遥控与 48/49/50 设值；手动升降步调节 47 仍可使用。
手动控制窗口可勾选“带 CP56 时标”；子站装置配置支持正常、否认、不应答及延迟策略。
源码在项目仓库；Windows 执行 build.ps1，macOS 执行 bash build-macos.sh 重建。
验证记录在 verification；已验证协议、交互和真实原生窗口加载，未作截图逐像素验收。

连接与退出
TCP 客户端点击连接后显示“等待连接”，目标尚未启动或断开时每秒自动重试，点击停止可取消。TCP 服务端保持监听等待连接。
添加装置成功后自动关闭窗口，添加失败则保留窗口供修正；重新打开时保留配置和 Modbus 递增地址。
关闭工程主窗口直接退出该工程的配置窗口、连接和自动任务，其他独立工程继续运行；不询问未保存更改；需要保留工程时请先手动保存。

点表直接改值
子站遥信／遥测的“值 / 状态”列可直接输入；遥信使用 0（分）或 1（合），遥测输入数值。回车或点击其他位置时提交，Esc 放弃本次输入。
IEC104 仅上送改动点，保留原点品质与描述；未连接或未激活104数据传输时只保存并提示未上送。Modbus 更新点表后供主站下次轮询读取，不发送无请求报文。
未改值不会重复上送；刷新不会覆盖正在输入的内容，发送失败保留输入供修正或重试。主站数值也可本地编辑，但不会向对端发送报文。

阅读显示
界面保留原来的深色蓝灰配色，提高正文、标签、表头与输入值的文字亮度，保留较大的表格和报文字号。报文窗口右上角可直接暂停／继续显示（快捷键 Space），通信和自动任务继续运行。

通道与装置
左侧上半区为通道列表，下半区为当前通道的装置列表，分别滚动。新增装置的点位数量默认由18改为50，已保存的装置数量不变。

布局与表格编辑
拖动左侧栏右边界调整宽度，拖动通道与装置之间的分隔条调整上下高度，默认各占一半；双击分隔条或选中后按Home恢复默认，方向键可微调，调整会记忆。
点表显示地址、码值、数值、品质、描述五列，均可直接编辑。回车或离开单元格提交，Esc取消；十六进制码值与数值对应，浮点数码值为IEEE754单精度编码。
主站修改只保存在本地；子站IEC104遥信/遥测的数值或品质修改会单点上送，Modbus等待主站读取。修改遥控/遥调的点表数值不会执行控制。
点表不再显示操作列；右键某行可进入详细配置或删除该点。

macOS 版本
需要 macOS 12.3 或更新版本，支持 Apple 芯片和 Intel。双击 protocol-simulator.app 启动，可拖入“应用程序”。布局、协议和工程文件与 Windows 版共用；窗口标题栏使用 macOS 原生按钮。Command+S 保存，点表右键打开详细配置或删除；串口选择 /dev/cu.* 设备。
本地构建采用 ad-hoc 签名，未进行 Apple 公证；网络下载后如系统拦截，可在“系统设置 → 隐私与安全性”中允许打开。

工程名称状态
右上角保留工程名，未保存到文件或有配置／点表修改时追加“（未保存）”；保存成功后去掉。取消或保存失败保留标记，连接状态变化和接收报文本身不添加标记。

报文与调试分隔
拖动调试信息框上方、框外的分隔条调整高度，双击或Home恢复默认130px；高度会记忆，弹窗不修改主窗口偏好。点数徽标只显示当前列表点数，悬停可查看装置总点数，总数不是点位上限。

新增规约配置
装置右键“修改装置参数”现在可以保存参数；校验成功后停止活动通道，保留点位数据，需手动重新连接。取消或参数无效不会断开连接。
104可配置周期总召、脉冲召唤、时间同步、超时重发、I/S帧窗口、S帧等待、U测试周期及地址字段字节数。脉冲召唤与校时也有手动按钮。子站支持单点/双点遥信、累计量及多种遥测格式，按SQ0/SQ1打包；单点编辑仍只上送该点。
主站“SOE / COS”打开独立事件窗口，保留设备时间、时间无效标记及接收时间；可按类别清除。缓存最多5000条，展示最近500条；接收报文与事件不标记工程为未保存。
Modbus主站可启用周期采集，按各装置配置范围轮询，保护事件按配置地址读取原始寄存器。遥测/脉冲支持16/32位整数、32位浮点与不同字节序；32位点占两个寄存器地址。RTU校验可选择高字节在前或在后。
Modbus读时/校时采用四寄存器映射，内容为CP56Time2a七字节加零填充；双方需配置同一首地址，子站启用“校时寄存器”。校时仅改变模拟装置时间。厂商私有时间和事件格式需按对应规约另行核对。
工程与CSV保存新增点位类型、格式、时标与时间品质；旧五列CSV仍可导入。
本机提供macOS通用应用和Windows x64交叉构建EXE；Windows EXE已核对嵌入前端及原ICO资源，不代表Windows实机验证。Windows原生构建仍由resources.ps1嵌入资源；macOS交叉构建读取同一脚本的版本字段，用等价的跨平台资源写入流程处理。
